# ft_lock

## Possible arguments :
- ```Image file``` : available background image for the lock (Defaults to None)
- ```Password text``` : Password preview so if it's something like ```Hello``` when you type instead of a dot it will display ```Hello``` (Defaults to infinite dots)
- ```Text``` : Commentary under the displayed username (Defaults to ```Back sOOn..```)
- ```Ft_colorname``` : The color of the text (Defaults to #5a7ab0)
- ```Username``` : The displayed username (Defaults to $USER)
- ```Timeout``` : The timeout time to set dpms off (Defaults to 5)
- ```Logout timeout``` : The time in minutes before allowing people to logout the computer using the escape key (Defaults to 30)
- ```Logout timeout force``` : The time where it auto logs off (Defaults to 42)
- ```API Key``` : The API key for the openweather API (Defaults to None)
- ```City``` : Available city for the openweather API (Defaults to Paris France)
